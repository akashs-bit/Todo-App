## 📝 React Todo List App

This is an interactive and user-friendly Todo List application built using React and Vite. It helps users manage their daily tasks efficiently with a clean interface and advanced features.

### ✨ Features

- ➕ **Add Tasks**: Instantly add new tasks with just a few keystrokes.
- ❌ **Delete Tasks**: Easily delete tasks you no longer need.
- ✅ **Mark as Complete / Incomplete**: Check or uncheck tasks to track progress.
- ⏱️ **Task Delay with setTimeout()**: Adds a delay effect for actions (e.g., auto-clear completed task or smooth animation using setTimeout).
- 💾 **State Management**: Tasks are managed using React state.
- 🧼 **Clear All**: Option to clear all tasks at once.
- ⚡ Fast and responsive UI built with **React** and **Vite**.
