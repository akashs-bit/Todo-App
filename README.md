## 📝 React Todo List App

This is an interactive and user-friendly Todo List application built using React and Vite. It helps users manage their daily tasks efficiently with a clean interface and advanced features.

### ✨ Features

- ➕ **Add Tasks**: Instantly add new tasks to your list.
- ❌ **Delete Tasks**: Remove no longer needed tasks.
- ✅ **Mark as Complete / Incomplete**: Easily toggle task completion.
- 🧠 **Persistent Storage with localStorage**: Tasks are saved in your browser's localStorage, so they don't disappear on refresh.
- ⏱️ **Delayed Actions using `setTimeout()`**: Adds delay effects to enhance user interaction (e.g., clearing or fading items).
- ♻️ **Clear All Tasks**: Clear all tasks simultaneously.
- ⚡ **Fast UI with Vite**: Built using React and bundled with Vite for high performance.
